# StableFlow SDK 3.1.7

**Release date:** 2026-11-02

All `@stableflow/*` packages bumped to `3.1.7` (`latest`).

## Highlights

Add Arc (chain id `5042`) as a CCTP USDC chain, send the OneClick CCTP permit `receipt_address` as the required EVM address, and raise the Solana peer dependency floor to `@solana/web3.js` 1.99 and Metaplex Umi 1.6.

## What's Changed

### `@stableflow/core`

- **Arc**: chain config (`chainId` `5042`, native token USDC, explorer `https://explorer.arc.io`, RPC `https://rpc.mainnet.arc.io`) and USDC `0x3600000000000000000000000000000000000000` with the CCTP service.

### `@stableflow/bridges`

- **CCTP**: Arc domain `26`, TokenMessenger `0x28b5a0e9C621a5BadaA536219b3a228C8168cf5d`, and TokenMinter proxy `0xa9d6546533Ad7929C7aF1B924a63cBe807a10809`.
- **`OneClickCCTPService.quote`**: `permitAdditionalData.receipt_address` is the caller's `evmAddress`. It previously used `params.recipient`.

### `@stableflow/utils-solana` and `@stableflow/wallet-solana`

- Peer dependency `@solana/web3.js` is `^1.99.0` (was `^1.98.4`).
- `@stableflow/wallet-solana` peer dependencies `@metaplex-foundation/umi`, `umi-bundle-defaults`, and `umi-web3js-adapters` are `^1.6.0` (were `^1.5.1`).

## Migration / Upgrade Notes

```bash
pnpm add @stableflow/core@3.1.7 @stableflow/bridges@3.1.7 @stableflow/utils-solana@3.1.7 @stableflow/wallet-solana@3.1.7
```

- **No breaking API changes.**
- Solana integrators need `@solana/web3.js` `^1.99.0`. Wallet-solana integrators also need Metaplex Umi packages `^1.6.0`.
- OneClick-then-CCTP quotes now put `evmAddress` in `permitAdditionalData.receipt_address`.
