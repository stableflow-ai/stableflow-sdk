# StableFlow SDK 3.1.8

**Release date:** 2026-11-17

All `@stableflow/*` packages bumped to `3.1.8` (`latest`).

## Highlights

Send the OneClick-then-CCTP second hop `refundTo` to the caller's `evmAddress`, and reject a quote before signing or broadcast when a submitted recipient or `refundTo` is the default middle-chain address.

## What's Changed

### `@stableflow/bridges`

- **`OneClickCCTPService.quote`**: the CCTP `refundTo` is `evmAddress`. It previously used the hardcoded middle-chain address.
- **`BridgeSFA.send` and `BridgeSFA.buildTransaction`**: throw `Invalid recipient address` before signing or broadcast when a submitted recipient or `refundTo` is `0x654E7B96E1DE0b54E53D9ae8082fC2219E66dAC3`, including its left-padded bytes32 form. `report` is unchanged. Dry placeholders left in `sourceQuoteParams` are not scanned.

## Migration / Upgrade Notes

```bash
pnpm add @stableflow/core@3.1.8 @stableflow/bridges@3.1.8
```

- **No breaking API changes.**
- OneClick-then-CCTP refunds now go to `evmAddress`.
- `send` and `buildTransaction` reject the default middle-chain address instead of submitting it.
