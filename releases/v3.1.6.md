# StableFlow SDK 3.1.6

**Release date:** 2026-08-21

All `@stableflow/*` packages bumped to `3.1.6` (`latest`).

## Highlights

Make OneClick quote wait time configurable (`oneclickParams.quoteWaitingTimeMs`, default `3000ms`), fix Solana OFT / FraxZero min-receive slippage to honor the caller’s `slippageTolerance`, and clarify low-amount quote errors for OneClick second-hop (middle-token) routes.

## What's Changed

### `@stableflow/bridges`

- **`oneclickParams.quoteWaitingTimeMs`**: optional wait time (ms) forwarded to OneClick `/v0/quote`. Defaults to `3000`. Pass `0` for the fastest quote.
- **`OneClickService.quote`**: no longer hardcodes `quoteWaitingTimeMs: 0`; uses the param above.
- **`formatQuoteError`**: for OneClick second-hop routes (`FraxZeroOneClick`, `Usdt0OneClick`, `CCTPOneClick`), low-amount errors now use the middle-token decimals/symbol and the message `Middle token amount is too low, at least {amount} {symbol}`. Direct OneClick routes keep `Amount is too low, at least {amount} {symbol}`.

### `@stableflow/hyperliquid`

- **`oneclickParams.quoteWaitingTimeMs`**: forwarded to `OneClickService.quote` (same default `3000`).

### `@stableflow/wallet-solana`

- **USDT0 `quoteOFT`**: `minAmountLd` uses `slippageTolerance || 0` instead of a `0.01` (1%) fallback, matching EVM.
- **FraxZero `quoteFraxZero`**: `minAmountLd` uses `slippageTolerance` instead of a hardcoded 1% (`(amountLd * 99n) / 100n`).

### Docs

- **`DEVELOPER_GUIDE.md`**: document `quoteWaitingTimeMs`; add `appFees` manual withdrawal steps for NEAR Intents.

## Migration / Upgrade Notes

```bash
# stable
pnpm add @stableflow/bridges@3.1.6 @stableflow/wallet-solana@3.1.6 @stableflow/hyperliquid@3.1.6
```

- **No breaking API changes.**
- OneClick quotes now wait **3000ms** by default (previously `0`). To keep the old fastest-quote behavior:

```ts
await BridgeSFA.getAllQuote({
  ...params,
  oneclickParams: {
    quoteWaitingTimeMs: 0,
  },
});
```

- Solana USDT0 / FraxZero min-receive amounts now follow `slippageTolerance`. If you previously relied on an implicit 1% floor, pass `slippageTolerance: 1` (1%).
- New error string for second-hop routes: `"Middle token amount is too low, at least {amount} {symbol}"`.
