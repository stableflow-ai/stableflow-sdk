# StableFlow SDK 3.1.4

**Release date:** 2026-07-31

All `@stableflow/*` packages bumped to `3.1.4` (`latest`).

Related channel builds from the same changeset:

- `3.1.4-rc-0f7f3e64ed-20260731` (`rc`)
- `3.1.4-canary-0f7f3e64ed-20260731` (`canary`)

## Highlights

Fix OFT (LayerZero / FraxZero / USDT0) amount precision by aligning SDK quotes and sends with on-chain `_removeDust` / `sharedDecimals` flooring. Prevents dust-related quote/send mismatches and adds clearer errors when the cleaned amount falls below the minimum cross-chain unit.

## What's Changed

### `@stableflow/bridges`

- **New OFT utilities** (`packages/bridges/src/utils/oft.ts`):
  - `OFT_SHARED_DECIMALS` — default shared decimals (`6`) used across LayerZero / FraxZero deployments
  - `removeOftDust(amountWei, localDecimals, sharedDecimals?)` — floors local-decimal amounts to OFT shared-decimals precision, matching on-chain `_removeDust`
- Re-exported from package entry (`@stableflow/bridges`)
- Extended `OFT_ABI` with `removeDust(uint256)` for on-chain dust removal when available

### `@stableflow/wallet-evm`

- **USDT0 (`quoteOFT`)**: clean `amountWei` via `removeOftDust` before building `sendParam`, fees, slippage, and approve amount; after `quoteOFT`, align `amountLD` with contract `amountSentLD`
- **FraxZero (`quoteFraxZero`)**: prefer on-chain `removeDust.staticCall`; fall back to local `removeOftDust` if the OFT has no public `removeDust`
- Return `"Amount below minimum cross-chain unit"` when the cleaned amount is `0`

### `@stableflow/wallet-solana`

- **USDT0 (`quoteOFT`)** and **FraxZero (`quoteFraxZero`)**: apply `removeOftDust` to amount / `minAmountLd` / fee / slippage paths
- Same minimum cross-chain unit error when cleaned amount is `0`

## Migration / Upgrade Notes

```bash
# stable
pnpm add @stableflow/bridges@3.1.4 @stableflow/wallet-evm@3.1.4 @stableflow/wallet-solana@3.1.4

# or a channel build
pnpm add @stableflow/bridges@3.1.4-rc-0f7f3e64ed-20260731
# pnpm add @stableflow/bridges@rc
```

- **No breaking API changes** for typical integrators.
- Optional: import and use the new helpers directly:

```ts
import { removeOftDust, OFT_SHARED_DECIMALS } from "@stableflow/bridges";

const amountLdClean = removeOftDust(amountWei, token.decimals);
```

- Quotes / sends may return a **slightly lower** `outputAmount` / send amount than the raw user input when local decimals > shared decimals (dust truncated). This matches on-chain OFT behavior.
- New error string: `"Amount below minimum cross-chain unit"` — handle in UI when amount is too small after dust removal.
