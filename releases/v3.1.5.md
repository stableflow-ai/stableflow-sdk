# StableFlow SDK 3.1.5

**Release date:** 2026-07-31

All `@stableflow/*` packages bumped to `3.1.5` (`latest`).

## Highlights

Fix `dry: true` quote crashes when callers omit optional `evmGasFees`. Document and pass through the optional pre-fetched EVM gas fee map on `GetAllQuoteParams`, and update `demo-full` to the recommended dry-preview then dry-false execute flow with a `useEvmGasFees` example hook.

## What's Changed

### `@stableflow/wallet-evm`

- **`estimateTransaction`**: use optional chaining for `evmGasFees?.[chainId]?.gasPrice` during `dry: true`. When fees are missing, fall back to `provider.getFeeData()` via existing `getEstimateGas` logic (same as `dry: false`).

### `@stableflow/bridges`

- **`GetAllQuoteParams.evmGasFees`**: new optional field for pre-fetched EVM gas fees keyed by chainId
- **`BridgeSFA.getAllQuote`**: forwards `evmGasFees` into each route's quote params
- **FraxZero / OneClick middle-chain gas estimate**: same optional-chain fallback when `evmGasFees` is absent

### Docs

- **`DEVELOPER_GUIDE.md`**: document `evmGasFees` on `GetAllQuoteParams` and note dry-quote usage in section 4.1

### Examples

- **`demo-full`**:
  - new `useEvmGasFees` hook (polls EVM `getFeeData` per chain, returns `byChainId`)
  - Get Quote uses `dry: true` and passes `evmGasFees`
  - Submit re-quotes with `dry: false` + `singleService`, then `BridgeSFA.send`

## Migration / Upgrade Notes

```bash
# stable
pnpm add @stableflow/bridges@3.1.5 @stableflow/wallet-evm@3.1.5
```

- **No breaking API changes.**
- Callers may omit `evmGasFees`; dry quotes no longer throw when it is undefined.
- Optional: pass pre-fetched fees to speed up dry EVM gas estimates:

```ts
await BridgeSFA.getAllQuote({
  ...params,
  dry: true,
  evmGasFees: {
    [chainId]: { gasPrice: "..." },
  },
});
```
